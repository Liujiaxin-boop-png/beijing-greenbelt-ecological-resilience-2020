# 北京二道绿隔及周边地区2020年生态韧性评价代码

本仓库提供论文《城市边缘区生态韧性评价与空间分异——以北京第二道绿化隔离地区及周边地区为例》的计算源代码、参数、输入哈希与数值核验记录。它是本研究的独立Python实现；所参照的上游InVEST 3.20.2源码另见 `REFERENCES.md`。

## 当前公开内容

- `run_full.py`、`src/core.py`：从已对齐栅格计算六套HQ/D情景、三种格网尺度、4/8邻接、等权算术/几何、CRITIC及去分量对照，汇总35个乡镇和四个方位象限。
- `parameters/`、`config/`：地类H/S、地类恢复系数、威胁距离、相对权重和等积坐标定义。
- `input_manifest.json`：完整运行所需输入的相对路径、SHA256和来源说明。
- `verify_full_run.py`、`verification/`：数值与栅格指纹核验程序及作者本地实际运行记录。

**当前仓库不包含输入栅格、研究边界派生上下文或历史参考CSV。** 因此仅克隆本仓库，尚不能在缺少这些文件时一键重现研究区结果。完整准备后输入在作者的本地复现包中；数据公开再分发条件尚未逐项确认。需要运行时，应先取得清单中的全部输入，并核对SHA256，不能以自行替换的数据声称复现原研究。

## 运行起点与方法

运行起点是已对齐的2020年分类/威胁栅格、完整格界和精确相交面积。原产品下载、WorldCover众数投影、OSM预处理及边界数字化属于上游准备，此入口不重新执行这些步骤。

R表示生境抵抗条件，Re表示地类恢复条件，A表示蓝绿结构调适条件，均为静态生态条件代理。主指数为三项等权算术平均；几何平均为共同约束对照。R与Re共享土地覆盖，相关性、CRITIC或情景一致性不应解释为独立生态证据。无目标斑块的A定义为0；支持不足保持缺测。

最近正值威胁距离、线性衰减和质量式按固定版本规则独立实现，未调用官方InVEST完整应用程序。两类威胁相对赋分1:1，归一化各0.5；k从主方案D最大值一半重新求得，并在替代情景间固定。

## 获得全部输入后的运行

实际核验环境为64位Python 3.12.14、NumPy 2.5.4、SciPy 1.18.1、Rasterio 1.5.2，依赖见 `requirements.txt`。无需GEE或Google账号。

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python run_full.py
.venv\Scripts\python verify_full_run.py
```

程序先检查输入哈希与栅格对齐，拒绝覆盖非空输出目录。若要保留旧运行，请在配置中使用新的空输出目录，并向核验入口传入该目录。地理制图的ArcMap、Excel及参考影像源另行保存；本仓库不承诺不同软件、字体与导出设置下成图文件字节完全一致。
